# Лабораторная работа 4

Сборка и запуск в Linux:

```sh
cd lab4/src
make
./parallel_min_max --seed 1 --array_size 10 --pnum 3
./parallel_min_max --seed 1 --array_size 10 --pnum 3 --by_files --timeout 10
./zombie
./process_memory
./psum --threads_num 4 --seed 1 --array_size 1000000
```

- `--timeout` — необязательное положительное число секунд. По истечении срока родитель отправляет детям SIGKILL, собирает их статусы и возвращает код 124. При таймауте неполный результат не выводится.
- `zombie` оставляет завершившегося ребёнка на 5 секунд, затем удаляет его через waitpid. В эти 5 секунд можно выполнить `ps -o pid,ppid,stat,comm -p PID` в другом терминале. PID ребёнка печатает программа.
- `process_memory` выводит виртуальные адреса. etext — конец кода, edata — конец инициализированных данных, end — конец BSS.
- `psum` использует GenerateArray из лабораторной 3. Sum вынесена в статическую библиотеку libsum.a. Время измеряется после генерации, включая создание и ожидание потоков. Сумма хранится в int64_t.
- Один Makefile выполняет задания 4 и 6. `make clean` удаляет результаты сборки.

Проверка таймаута:

```sh
sh ../tests/check_timeout.sh
```

Тест временно останавливает детей сигналом SIGSTOP через отдельную тестовую библиотеку. Рабочая программа остаётся без искусственных задержек. Оба режима должны вернуть 124.

В копии find_min_max.c исправлена граница цикла: диапазон [begin, end), условие i < end.
В process_memory.c исправлены устаревшие объявления функций и формат адресов на %p.
